# My SQL Portfolio

This repository showcases my SQL skills through complex queries for data analysis.

## Queries
- [Top 3 Selling Products per Category](top_selling_products.sql): Ranks products by sales within each category.
- [Customers With No Orders in Last 6 Months](inactive_customers.sql): Identifies inactive customers for re-engagement.
- [3-Month Moving Average of Revenue](moving_avg_revenue.sql): Tracks revenue trends over time.
- [Employees Earning Above Department Average](above_avg_employees.sql): Finds high earners per department.
- [Customers With Highest Total Spending](top_spending_customers.sql): Identifies top-spending customers.

## Tools Used
